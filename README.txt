# Jai weds Manisha Invitation

## Folder structure
- `index.html` — invitation page structure and content
- `css/styles.css` — all styling, colors, layout, animations, and responsive rules
- `js/script.js` — door-opening interaction, countdown, drawing/interaction logic, and WhatsApp share link

## Run locally
Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

Google Fonts require an internet connection. The rest of the page is local.
